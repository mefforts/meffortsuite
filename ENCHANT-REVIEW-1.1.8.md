# Enchant Queue 1.1.8 review

The user reported queued 0, a selected native recipe/item and an empty setup list without an Add action. Source review found legacy ItemButtonTemplate inheritance in setup construction. The native reference's Blizzard_ItemButton/Shared/ItemButtonTemplate.xml declares ItemButton as an intrinsic widget. The new setup creates that widget directly instead of depending on a legacy virtual template.

A strict widget-contract fixture rejects ItemButtonTemplate. Under that condition, the 1.1.7 source aborts setup, caches a partial panel and creates zero Add controls. This reproduces the failure shape in simulation; the original live report did not include the constructor stack. The earlier permissive frame mock missed this contract. The updated factory check stays in the regression suite.

Construction now starts hidden with an unnamed private frame. The public panel and Escape reference are registered only after all widgets are created. A construction exception hides the incomplete frame, clears partial references, preserves queue data, records the actual error and permits an explicit retry. Repeated feedback is limited. The completed popup is raised so its controls are accessible.

Setup has an Add selected action, a repeat count starting at one, and empty-list guidance. Add uses the native recipe selection and can snapshot the native target's verified location/GUID when no target is configured. It does not cast or alter the native allocation. Existing configured targets are not silently replaced; an empty queue can recover a missing saved target. The target slot can explicitly import the native item on click, still supports drag selection, and supports Alt-click clearing.

Next remains gated by actual queue entries and verification. Inventory events update readiness while configuration is closed, and returning to the native recipe tab refreshes a previously disabled control. Tooltip/status query the current blocker, expose the actual enabled state and include construction errors. The status command identifies the build; exports include the richer state. No automatic enqueue/craft or confirmation was added.

All 32 regression scripts pass: 410 unit-test methods plus five tooltip script checks. Enchant Queue has 48 cases. New cases cover the unavailable legacy template with complete native-widget controls, Add selected reusing the native target, preservation of configured targets, stale empty-target recovery, explicit target import, hidden/reportable/retryable construction failure, current-blocker feedback, closed-window inventory readiness and returning to the recipe tab. Existing casting, replacement, quantity, GUID, uncertainty and lifecycle safeguards remain tested.
