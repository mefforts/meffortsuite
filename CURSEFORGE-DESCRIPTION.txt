MeffortSuite

Inventory, profession, quest, combat and travel tools for WoW Forever (Interface 16001), with familiar Blizzard-style controls.

Open /msuite or Options > AddOns > MeffortSuite. Each feature can be configured independently, and the master switch retains your saved preferences.

Bags and banking
- Fast auto loot is on by default for unset preferences (saved OFF choices remain off) and follows native auto-loot/modifier choices, with native confirmations and combat handling.
- Quest reward vendor labels show full-stack prices without choosing a reward; compact layouts retain tooltip values.
- Floating loot totals with native coin icons, a gentle rise and fade, and confirmed loot money plus item vendor value. All item qualities are included by default; grey-only mode is available. Optional Auctionator AH estimates and a combined vendor + (AH) display fall back to vendor prices and start off.
- A native backpack empty-slot counter, enabled by default with restoration of the prior game setting.
- Bag sorting, grey-item sales, repairs using personal gold, reagent deposits and personal-bank sorting.
- Per-character banking inclusion and exclusion lists using exact item names or numeric IDs.

Fishing and sounds
- Right-click fishing while a fishing pole is equipped, with single- or double-click preferences.
- Optional Quiet fishing audio under Fishing or Sounds, off by default per character. Equipping a fishing pole mutes music, ambience and dialogue without requiring a cast. Removing the pole or disabling the feature restores previous volumes. Manual volume changes are retained; sound effects and master volume stay unchanged, so other effects remain audible alongside the bite.

Combat and interface
- Right-click ranged attacks, with native Throw/Bow/Gun/Crossbow selection for warriors and rogues even during combat weapon swaps. One macro is retained, class defaults are unchanged, and account/custom macros are preserved.
- A conservative target-range warning and Mage Arcane Blast tracking on Blizzard Tracked Buffs.
- Custom action-bar keybinding text with a live position preview. Native red out-of-range warnings take priority over custom colors.
- English spell explanations, tooltip badges, palettes and rank alerts.

Quests and travel
- Spacebar quest priority, numbered dialogue choices and native menu labels where the layout permits them.
- Single-option shop/service shortcuts and flight-master dialogue shortcuts with Shift bypasses.
- /way coordinate commands and a waypoint arrow using the client's zone data.

Install the MeffortSuite folder in Interface/AddOns and reload. Existing saved preferences are retained. Floating loot uses an available nameplate screen position or the loot-click position; AoE loot is combined. Loot receipt formats use native localized messages where available. Spell explanations and tooltip-header parsing use English data. Optional standalone MeffortWand takes priority over the suite's wand controls.

If an interface action fails, export before reloading or logging out: type /msuite export, click Select report, and press Ctrl+C (Command+C on Mac). Switch out of the game and paste the report into your bug report to Mefforts with Ctrl+V (Command+V on Mac). Include what you clicked or pressed and the NPC or window involved. A single chat notice explains these steps for reported Suite/Wand or generic blocked actions; no Lua error is needed. /msuite diagnostics shows session status in chat.

Feature pages include setup guidance and a ? help page. Loot controls are grouped under Bags > Looting & loot value. Floats last six seconds by default, with an adjustable 2–12 second duration.

Sounds includes an optional native pet-category mute and advanced muting of verified sound-file IDs. Both start off. Native pet muting is broader than footsteps; shared sound files affect every source using them. Prior settings restore on disable, with failed recovery retained.

Restore Defaults opens a review before resetting account/current-character preferences and reloading. Bank item lists, custom sound-file lists, macros and game keybindings are retained. Enchant Queue has been removed.

Banks use the general single-option service shortcut and dialogue keys; the dedicated Orgrimmar banker shortcut is removed.
