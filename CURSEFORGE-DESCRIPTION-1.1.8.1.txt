# MeffortSuite

MeffortSuite brings together action bar, minimap, combat, quest, fishing, and inventory tools for **World of Warcraft: Forever**. Type `/msuite` or choose **MeffortSuite** from its minimap menu to open settings.

## Features

- Customize action bar keybind labels and display mana costs as a whole percent of maximum mana. Adjust the mana label’s color, size, and position in **Bars**.
- Group supported addon buttons in the MeffortSuite minimap menu. It includes MeffortSuite settings and preserves each entry’s left- and right-click actions. Drag the round icon along the minimap edge to move it.
- Set up right-click or Shift + right-click wanding, shooting, and throwing for supported classes. Show an out-of-range dot or track Arcane Blast stacks and time on Blizzard’s Tracked Buffs.
- Double right-click to fish while holding a pole. Enable WoW’s Interact Key, aim at the bobber, and double right-click again when it splashes. Optional first-person zoom and quieter fishing audio make bites easier to spot.
- Speed up auto loot and display a floating total with vendor values or optional Auctionator estimates. Mages can enable right-click comprehension for untranslated scrolls under **Loot**.
- Sort bags and the personal bank, sell junk, repair with personal gold, and display free bag slots. Configure automatic reagent deposits and item exceptions.
- Use Space to advance quest dialogue and accept eligible confirmations. Press 1–9 to choose dialogue options. Open the flight map at recognized flight masters or place a map pin with `/way X Y`.
- Highlight spell details with customizable tooltip badges and higher-rank reminders. Mute native pet sounds or selected sound files.

The mana labels and minimap menu start on. Each has a toggle in the settings.

## Compatibility

Built for **WoW Forever 1.60.1**, interface 16001. Auctionator is optional. An active standalone MeffortWand takes priority for wand controls. Spell tooltip enhancements use English client text.

To report an issue, use `/msuite export` to copy the diagnostic report before reloading.
