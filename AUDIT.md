# MeffortSuite 1.1.5 release audit

This release retains the fishing/audio fixes that the user reports are working and adds explicit player-facing support instructions for blocked interface actions. The release version is 1.1.5 throughout current metadata and documentation.

Reported Suite/Wand blocks, generic native interface failures and blocked tracked Suite calls receive one local chat notice per UI session. The notice explains /msuite export, Select report, Windows/Mac copy and paste shortcuts, switching outside the game, sharing with Mefforts, the triggering action/NPC/window, and exporting before reload/logout. Repeated failures remain counted without repeated notices. The report window opens only on request and repeats the sharing instructions in constrained multiline text; it scales to small viewports and retains automatic selection, focus cleanup and reuse.

Client-reported addon names remain unchanged. A tracked Suite call can trigger support guidance when the client attributes the block elsewhere; the notice does not assign blame. Unrelated addon/macro events remain silently recorded. Bounded history, operation context, event stacks, nearby-call correlation and secret-value handling remain in place. Reports require no Lua exception and warn that reload/logout clears the session history.

Nine diagnostic scenarios include both blocked/forbidden event types, 80 repeats with master/login announcements disabled, a client attribution mismatch during a tracked Suite call, generic localized warnings, unrelated errors, secret values, export commands, user-facing report contents and explicit window sizing/selection behavior. All 29 Suite regression scripts pass, including actual local MeffortWand modules in both load orders. The previous fishing, banking, range-color, inventory and profession safeguards remain covered.

All 28 shipped text/data/source files pass the prompt/model/transcript residue scan. New implementation text is limited to concise application instructions; no new source comments were added. Legal and attribution notices remain byte-identical to 1.1.4h. The ZIP contains one MeffortSuite folder with exactly 32 files, including 21 Lua modules, four textures, bindings, metadata, player documentation and legal notices. Tests, build scripts, originals, source snapshots and audit records are excluded. Version agreement, references, source/ZIP byte equality, permissions, reproducibility and ZIP integrity are validated.

Live Forever layout, clipboard shortcuts and native event delivery remain client checks in VALIDATION.md. User-reported fishing/audio success does not establish every taint path. CurseForge game-version selection must match the intended client. Preparation does not upload to CurseForge or publish the environment.
