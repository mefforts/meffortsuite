# MeffortSuite 1.1.6 release audit

The complete feature/variant review is in FEATURE-AUDIT-1.1.6.md. All 21 Lua modules, bindings, metadata, documentation and packaged assets were included. The review inventories every documented feature/mode and distinguishes simulated API checks from native Forever behavior.

Two reported ranged failures reproduce in the 1.1.5 baseline: a combat Throw-to-Gun swap keeps Throw, and a Throw-to-Gun-to-Bow sequence with Wand's version-10 manager creates two macros and leaves input unbound. Warriors and rogues now use one verified native conditional macro for all four physical weapon types. No macro rewrite is needed during a combat swap. Class/mode/weapon eligibility, full slots, unknown caches, manual macro edits and combat reload are covered.

The shared manager upgrades known tables in place to version 11 while preserving Wand's normal and sequence API. It preserves custom/account macros, verifies writes and macro lengths, avoids synchronous update recursion and deletes duplicates only on explicit request. Explicit cleanup retains the selected attack/sequence and refreshes peers after reindexing. Actual local Wand runtime modules are exercised in both load orders, including sequence mode and Suite cleanup.

Additional fixes prepare single-click fishing before the first press, unify dedicated flight shortcuts with indexed/delayed/cost/Shift guards, correct nested service selection markers, recheck selective-bank access/destination after pickup, restore only the matching owned cursor item, reject unknown stack counts and invalid merchant amounts, acknowledge native refusals accurately, and reject invalid native map/geometry values. The default double-fishing, equipment-only quiet audio, native red range warnings, loot-value choices and blocked-action export instructions remain covered.

All 32 regression scripts pass: 390 unit-test methods plus five tooltip script checks, with additional parameterized scenarios within methods. Lua 5.1 compilation, TOC/bindings, full addon load/settings/master transitions, package reproducibility, ownership and compatibility checks pass. The clean source scan covers all 28 shipped text/source/data files. Comments are concise API, ownership, ordering or safety explanations; no prompt/model/transcript remnants are present. Legal/attribution notices remain byte-identical to 1.1.5.

The ZIP contains exactly one MeffortSuite folder and 32 files: 21 Lua modules, metadata, bindings, four textures, player documentation and legal notices. Tests, audit files, originals, baselines and build scripts are excluded. Versions agree across current runtime, TOC, About fallback, documentation, upload notes and archive name. Archive/source bytes, references, permissions and integrity are verified.

Actual native equipped-weapon conditions, input ordering, taint, rendering and server responses remain client checks. See the audit and VALIDATION.md before broad release. This review does not certify every third-party combination. No CurseForge upload or environment publication is performed by preparation.
