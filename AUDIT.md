# MeffortSuite 1.1.4h release audit

This patch changes quiet fishing audio to use equipment alone and repairs rejection of world clicks with an empty native mouse-focus result. The banker, loot-value, action-text range-color and shared-input ownership changes from the preceding release remain unchanged.

Quiet audio activates when its per-character setting is enabled, the suite is active and a fishing pole is equipped. It does not require a cast, channel or spell API. Casting, interruption, looting and combat do not switch it off. Removing the pole or disabling the feature/master restores the owned channel volumes. Music, ambience and dialogue are the only channels changed; effects and master volume remain unchanged. Manual nonzero volume changes are preserved. Validated saved recovery, failed-restore retry and logout cleanup remain in place. Audio uses equipment/world events without idle polling or casting bindings.

A successful empty GetMouseFoci/GetMouseFocus result, or UIParent background, is accepted even before native camera turning starts. Explicit UI frames and absent/failed focus APIs still reject fishing gestures. The existing between-click secure binding, combat disarm, time limits and cleanup remain intact. Fishing status identifies the focus API/background and counts casting-button releases; receiving a release does not prove server cast success.

The updated tests reproduce both failures against 1.1.4g: the empty-focus double gesture casts zero times, and a pole with no channel leaves the original music volume unchanged. Updated code passes these cases. Coverage includes legacy fallback, explicit UI rejection, missing/erroring APIs, equip/unequip in combat, casting-independent audio, manual volume changes, restoration and whole-TOC master disable without a channel API. All 29 Suite regression scripts pass, including actual local MeffortWand modules in both load orders.

Shipped text, Lua, XML, metadata and data pass the prompt/model/transcript residue scan. Comments remain concise API or safety notes; legal and attribution notices are byte-identical to 1.1.4g. The package contains exactly one MeffortSuite folder with 32 files, including 21 Lua modules, four textures, bindings, metadata, documentation and legal notices. Tests, review records, source snapshots and build scripts are excluded. Source/ZIP bytes, versions, permissions, references and ZIP integrity are checked.

Actual Forever hardware dispatch, taint and sound-channel behavior remain client checks described in VALIDATION.md. This preparation does not upload to CurseForge or publish the environment.
