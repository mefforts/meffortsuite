# MeffortSuite 1.1.4f release audit

The release includes the all-quality loot-value display and the existing Bags mode toggle. The new behavior change gives native red action-bar range warnings priority over configured hotkey colors. Blizzard's native range-indicator callback supplies current colors; readable warning red is retained through styling, binding, page and font refreshes. Normal selected colors resume when the native warning clears outside combat. Disable cleanup preserves current native warning colors instead of restoring stale captured red.

Private weak tables distinguish colors written by the addon from native colors, including a user-selected red palette. Range hooks reconcile color without rewriting geometry. Hook installation, color and layout changes defer during combat; unreadable or secret colors are left alone. No new range probes, frame polling, native method replacement, binding changes or protected action calls are added.

All shipped source, data, XML, metadata and documentation were scanned for model names, prompt exchanges, transcript markers and draft labels. Comments were reviewed individually; repeated module narration was removed and verbose notes shortened. Remaining comments explain API contracts, protected ownership, ordering, localization, timing or safe item transfers. License and source-data attribution notices are retained verbatim. Legitimate Blizzard replacement-prompt messages and supported diagnostic aliases remain player-facing application text.

The archive contains exactly one MeffortSuite folder with 20 Lua modules, the TOC, binding XML, four referenced textures, player documentation and required legal notices. Tests, review records, uploaded originals, caches, build scripts and prior archives are excluded. Versions match across runtime, TOC, About fallback, documentation and ZIP filename. Source/ZIP equality, file permissions, case-sensitive references, residue checks and ZIP integrity are validated by the package builder and archive review.

Ten new range-color tests join the existing regressions. A lexical comparison confirms that comment-only changes in other feature modules retain executable tokens and string literals. The user has reported positive in-game results for the loot display; this does not establish complete client validation of combat protection or the range-color fix. Follow VALIDATION.md for those checks. CurseForge game-version selection must match the Forever client; no upload or environment publication is performed by package preparation.
